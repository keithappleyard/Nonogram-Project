# Nonogram-Project

This project is a nonogram puzzle game written in java using the swing library. To play, click on a square to cycle through colours to fill the image so it matches the description according to the labels next to the image.

Below I will explain what each button underneith the image does.

Load:
This button allows you to navigate through your files and choose a BMP image to import on to the program.

Submit:
This button makes the program check each square to see if they are the right colour. If it is not, the program will highlight wrong coloured square to indicate that it is the wrong colour.

Solve:
This button reveals the colour on each square and fills out the puzzle for you.

Reset:
This button resets the puzzle and allows you to restart.
